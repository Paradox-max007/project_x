    16→
    17→Build a professional manpower-company management platform for managing:
    18→
    19→* Employees/workers
    20→* Employee documents
    21→* Employee assignments
    22→* Client sites/projects
    23→* Team leaders
    24→* Daily attendance
    25→* Overtime
    26→* Employee ratings
    27→* Warnings
    28→* Fines
    29→* Leave requests
    30→* Employee cancellation/deletion requests
    31→* Uniform/PPE distribution
    32→* Notifications
    33→* Administrators
    34→* Role/menu permissions
    35→* Dashboard analytics
    36→* Employee CV/report generation
    37→* WhatsApp sharing
    38→* Audit history
    39→* Secure document storage
    40→
    41→The new system should reproduce the important business capabilities of the reference application while being:
    42→
    43→1. More secure
    44→2. More scalable
    45→3. Easier to maintain
    46→4. Better structured for Supabase
    47→5. Easier for an AI coding agent to develop
    48→6. Fully responsive
    49→7. Ready for future mobile applications
    50→8. Ready for multiple manpower-company branches
    51→9. Suitable for production deployment
